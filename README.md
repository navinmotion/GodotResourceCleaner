# Godot 3.x Compatibility

This repository includes a dedicated branch, `godot-3.x`, providing compatibility with Godot 3.x through minor API adjustments.

The goal of this branch is to maintain the original functionality of the tool while enabling its use in projects that have not yet migrated to Godot 4.

---

## ✅ Scope of Changes

- Updated API calls to match Godot 3.x equivalents
- No intentional changes to core behavior or features
- Kept as close as possible to the upstream implementation

---

## 🧪 Tested Version

- Verified with **Godot 3.5.3**
- Likely compatible with other 3.x versions, but not explicitly tested

---

## 🚀 Usage

Usage remains identical to the original project. Please refer to the [main documentation](https://github.com/ijoschek/GodotResourceCleaner) for setup and instructions.

---

## 🔀 Branch Structure

| Branch | Description |
|--------|-------------|
| `godot-4.x` | Tracks the original Godot 4 version |
| `godot-3.x` | Contains the Godot 3.x compatible version |
